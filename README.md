# StreameX Clone

Modern Next.js streaming site with admin dashboard.

## Features
- Movies, Series, Live TV browsing
- TMDB metadata fetching by IMDB ID
- Embed player with fallback chain
- Admin dashboard with bulk import
- SEO per page (JSON-LD, meta tags)
- IPTV promo banner
- Custom embed providers

## Setup
1. Install deps: npm install
2. Set TMDB API key in admin settings
3. Run: npm run dev

Default admin login: admin / admin
